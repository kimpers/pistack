# Real application verification

Prefer the repository's existing harness and project-local `.pi/skills/verify-*/SKILL.md`. Inspect its Launch, Doctor, Drive, Evidence and Cleanup contract before running. `control-cli` and `control-ui` are upstream concepts, not bundled Pi tools. Browser/Electron proof may use the selected pi-agent-browser-native integration only with a working CLI/browser runtime; real CLI/TUI input may use pi-interactive-shell. Read the installed provider's public skill/tool schema before calling it. HTTP, existing Playwright/Cypress tests and repository PTY harnesses remain valid when they prove the actual user path. Do not install missing runtimes automatically.

The parent coordinates driving; source-reader children do not share a running app. A live verifier needs a discovered profile with its actual control tools and providers loaded. Keep independent instances isolated by worktree, port, data directory and browser profile; a worktree alone does not isolate app state. Missing auth, browser, PTY, image inspection, recording or platform access is a named blocker/unverified claim, not permission to switch agent execution protocols.

Capture the input/action and observable result, build/head identity, side effects and prerequisite checks. Use bounded logs with stdout, stderr and exit status for CLI checks; screenshots and semantic snapshots for visual claims, image diffs for pixel parity. Inspect images when that capability exists; otherwise disclose that images were captured but not visually inspected. Teaching can use ASCII or Mermaid instead of an unavailable image-generation tool; diagrams are explanation, never runtime proof. Video requires an available recording runtime; never claim it from a screenshot.

Only stop processes/sessions created by this task, by their exact returned IDs/PIDs. Never kill by process name or dismiss all background sessions. Re-do doctor after surprising behavior, clean failed iterations, and confirm proof files survive teardown. Untracked files are not automatically disposable. No production state, customer traffic or external messages for a proof without authorization.
